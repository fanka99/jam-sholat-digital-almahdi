Bootloader & Firmware ESP32.

Panduan langkah demi langkah mengisi Bootloader, Tabel Partisi, Boot App, dan Firmware utama Jam Sholat Digital Almahdi pada varian ESP32 DevKit, ESP32-S2 (HD-WF1), dan ESP32-S3.

1

Persiapan Tool Flasher & File Binary

Software dan 4 file esensial yang wajib disiapkan sebelum flashing chip baru/kosong.

Untuk board ESP32 yang masih baru (pabrikan kosong), wajib di-flash 4 komponen file binary agar sistem operasi ESP-IDF dapat booting dan menjalankan program jam sholat:

  • 1. Bootloader (bootloader.bin): Bertugas menginisialisasi clock, flash SPI, dan memanggil partisi boot.
  • 2. Partition Table (partitions.bin): Peta partisi memori flash internal (alokasi memori program & storage EEPROM/LittleFS).
  • 3. Boot App Sub-system (boot_app0.bin): Penentu slot partisi aktif untuk mendukung update nirkabel OTA.
  • 4. Firmware Utama (jamsholat_xxx.bin): Program inti Jam Sholat Digital Almahdi yang didapatkan langsung dari Bot Telegram @LicjwsAlmahdi_bot.
Software Flasher yang Direkomendasikan:
• Espressif Flash Download Tools (Resmi GUI): Paling mudah digunakan, tinggal masukkan file dan alamat memori lalu klik START.
• esptool.py (CLI Python): Cocok untuk teknisi yang terbiasa menggunakan Command Prompt / Terminal.
2

Peta Alamat Memori (Flash Offset Map)

Alamat heksadesimal wajib pada memori flash agar chip tidak bootloop.

A. Varian ESP32-S2 (Huidu HD-WF1 & Wemos S2)

Nama File Alamat Heksadesimal (Offset) Keterangan
bootloader.bin 0x1000 Bootloader resmi ESP32-S2
partitions.bin 0x8000 Tabel partisi (Default / Minimal SPIFFS)
boot_app0.bin 0xe000 Data inisialisasi boot OTA
jamsholatp10s2.ino.bin 0x10000 Firmware Jam Sholat P10 HD-WF1 Almahdi

Konfigurasi SPI ESP32-S2: SPI SPEED: 80MHz | SPI MODE: DIO | FLASH SIZE: 32Mbit / 4MB.

B. Varian ESP32 DevKit (P5 RGB / P2.5 / P10 RGB)

Nama File Alamat Heksadesimal (Offset) Keterangan
bootloader.bin 0x1000 Bootloader dual-core ESP32
partitions.bin 0x8000 Tabel partisi OTA
boot_app0.bin 0xe000 Data inisialisasi boot OTA
firmware_esp32_rgb.bin 0x10000 Firmware Jam Sholat RGB Almahdi

Konfigurasi SPI ESP32 DevKit: SPI SPEED: 40MHz / 80MHz | SPI MODE: DIO | FLASH SIZE: 32Mbit / 4MB.

C. Varian ESP32-S3 (HD-WF2 / DevKit S3)

Nama File Alamat Heksadesimal (Offset) Keterangan
bootloader.bin 0x0000 Catatan: ESP32-S3 bootloader dimulai dari alamat 0x0
partitions.bin 0x8000 Tabel partisi 8MB / 16MB
boot_app0.bin 0xe000 Data inisialisasi boot OTA
firmware_s3_rgb.bin 0x10000 Firmware Jam Sholat S3 DMA

Langkah Flashing via GUI (Flash Download Tool)

Metode termudah menggunakan software resmi Espressif.

  1. Buka software flash_download_tool_xxx.exe.
  2. Pada jendela pop-up awal, pilih:
    • ChipType: Pilih tipe chip lo (ESP32-S2, ESP32, atau ESP32-S3).
    • WorkMode: Pilih develop.
    • LoadMode: Pilih uart. Klik OK.
  3. Di tab SPIDownload, masukkan ke-4 baris file binary dan isi alamat heksadesimalnya (centang kotak checklist di sebelah kiri masing-masing file).
  4. Atur parameter radio button di bawahnya:
    • SPI SPEED: 80MHz (atau 40MHz jika kabel panjang).
    • SPI MODE: DIO.
    • FLASH SIZE: 32Mbit (4MB) untuk S2/DevKit, atau 64Mbit/128Mbit untuk S3.
  5. Pilih COM Port USB modul lo dan set BAUD: 921600 (untuk kecepatan maksimal) atau 115200.
  6. Masuk Mode Download: Tekan dan tahan tombol BOOT (IO0) pada board, lalu colok kabel USB (atau tekan tombol RESET sekali sambil tombol BOOT tetap ditahan), kemudian lepas tombol BOOT.
  7. Klik tombol START. Kotak status akan berubah menampilkan progres bar hijau DOWNLOADING.
  8. Tunggu hingga muncul tulisan FINISH berwarna hijau.
  9. Tekan tombol RESET (EN) pada board, atau cabut dan colok kembali kabel power USB. Modul langsung aktif dan memancarkan Wi-Fi JWS!
Tips Sukses: Setelah flashing pertama kali selesai, untuk update firmware berikutnya lo nggak perlu colok kabel USB lagi! Cukup gunakan fitur Update Firmware Nirkabel (OTA) lewat browser di IP 11.11.11.11/update.
4

Flashing via Command Line (esptool.py)

Perintah langsung 1-baris tanpa install software GUI tambahan.

Jika lo memiliki Python / esptool di komputer, jalankan satu baris perintah sakti berikut (sesuaikan nama port COM3 dengan port USB lo):

Perintah Flash untuk ESP32-S2 (Huidu HD-WF1):

esptool.py --chip esp32s2 --port COM3 --baud 921600 --before default_reset --after hard_reset write_flash -z --flash_mode dio --flash_freq 80m --flash_size 4MB 0x1000 bootloader.bin 0x8000 partitions.bin 0xe000 boot_app0.bin 0x10000 jamsholatp10s2.ino.bin

Perintah Flash untuk ESP32 DevKit (P5 / P2.5 RGB):

esptool.py --chip esp32 --port COM3 --baud 921600 --before default_reset --after hard_reset write_flash -z --flash_mode dio --flash_freq 80m --flash_size 4MB 0x1000 bootloader.bin 0x8000 partitions.bin 0xe000 boot_app0.bin 0x10000 jamsholat_rgb.bin

Troubleshooting: Solusi Kendala Saat Flashing

Solusi cepat jika proses flashing macet atau tidak terhubung.

  • Error: "Failed to connect to ESP32: No serial data received"
    Board belum masuk mode download. Tahan tombol BOOT, tekan tombol RESET satu kali, lalu lepas tombol BOOT sebelum klik START.
  • Port COM tidak terdeteksi di Device Manager:
    Pastikan driver USB sudah terinstall:
    • Driver CP210x (untuk board dengan chip kotak Silicon Labs).
    • Driver CH340 / CH341 (untuk board clone murah).
    • Driver ESP32-S2 / S3 USB JTAG / CDC jika menggunakan port USB native.
  • Setelah diflash layar display tetap gelap / tidak muncul sinyal Wi-Fi:
    Pastikan file boot_app0.bin di alamat 0xe000 tidak lupa dimasukkan. Tanpa file ini, bootloader tidak tahu partisi aplikasi mana yang harus dijalankan.
