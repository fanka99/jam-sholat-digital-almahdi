Manajemen Catu Daya (Power Supply) & Aturan Grounding Wajib

Kunci utama JWS awet, tidak sering reset sendiri, dan LED tidak berkedip redup.

  • Gunakan Power Supply Berkualitas: P10 Mono (5V 5A s/d 20A) & P5 RGB (5V 20A+ anti-drop).
  • Golden Rule (Common Ground): Semua pin GND (GND Power Supply, GND Panel LED, GND Mikrokontroler, dan GND DFPlayer) WAJIB disatukan menjadi satu titik ground bersama.
  • Jalur Daya Terpisah: Tarik kabel daya 5V tebal langsung dari PSU ke panel LED. Jangan memberi makan daya panel LED dari pin 5V mikrokontroler!
  • Resistor 1kΩ pada RX DFPlayer Mini: Pasang resistor 1kΩ seri pada jalur pin RX modul DFPlayer untuk meredam noise desis (hiss) audio.

Langkah Flashing via GUI (Espressif Flash Download Tool)

Metode resmi termudah untuk pemula & teknisi.

  1. Buka software flash_download_tool_xxx.exe.
  2. Pilih ChipType (ESP32-S2, ESP32, atau ESP32-S3), WorkMode: develop, LoadMode: uart.
  3. Masukkan ke-4 baris file binary di atas beserta alamat heksadesimalnya (centang checklist di sebelah kirinya).
  4. Atur parameter: SPI SPEED = 80MHz, SPI MODE = DIO, FLASH SIZE = 32Mbit (4MB).
  5. Pilih COM Port USB modul dan set BAUD: 921600 (atau 115200).
  6. Masuk Mode Download: Tahan tombol BOOT (IO0) pada board, colok kabel USB (atau tekan tombol RESET sekali), lalu lepas tombol BOOT.
  7. Klik tombol START & tunggu hingga status bar hijau berubah menampilkan tulisan FINISH.
  8. Tekan tombol RESET (EN) pada board. Selesai! Modul langsung aktif dan memancarkan Wi-Fi JWS!

Opsi Perintah 1-Baris Command Line (esptool.py):

esptool.py --chip esp32s2 --port COM3 --baud 921600 --before default_reset --after hard_reset write_flash -z --flash_mode dio --flash_freq 80m --flash_size 4MB 0x1000 bootloader.bin 0x8000 partitions.bin 0xe000 boot_app0.bin 0x10000 jamsholatp10s2.ino.bin
